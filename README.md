# Emoji Blaster

A typing-defense game built in Construct 3, exported as a static HTML5 webapp.

## How this repo is structured

This repo contains the **exported HTML5 build** of the game (from Construct 3's
`Export → HTML5 Website` option) — not the editable `.c3p` project file. The
`.c3p` source file is kept separately in Construct 3's cloud project storage.

```
/
├── index.html          ← entry point
├── scripts/             ← game engine + logic (auto-generated by Construct 3)
├── images/               ← sprite/emoji assets
├── media/                ← sound assets, if any
└── render.yaml           ← Render.com static site deploy config
```

## Running locally

Since this is a static site, any local static server works:

```bash
npx serve .
```

Then open the URL it prints (usually `http://localhost:3000`).

## Deployment

This repo is configured to deploy automatically on [Render](https://render.com)
as a static site. See `render.yaml` for the config. Any push to `main` will
trigger a redeploy.

## Updating the game

1. Open the project in Construct 3.
2. Make your changes.
3. `Export → HTML5 Website`.
4. Replace the contents of this repo with the new export (keep `render.yaml`
   and this `README.md`).
5. Commit and push — Render redeploys automatically.
